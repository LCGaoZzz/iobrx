# Bundled reference data — provenance and licenses

The files in this directory are copied **unmodified** from the
[IOBRpy 0.2.1](https://github.com/IOBR/IOBRpy) distribution, which is
released under the MIT License:

    MIT License

IOBRpy repackages published academic references; the original sources include
(among others):

- LM22 signature — Newman et al., *Nat Methods* 2015 (CIBERSORT)
- EPIC TRef/BRef — Racle et al., *eLife* 2017
- quanTIseq data — Finotello et al., *Genome Med* 2019
- MCP-counter markers — Becht et al., *Genome Biol* 2016
- ESTIMATE data — Yoshihara et al., *Nat Commun* 2013
- BayesPrism reference — Chu et al., *Nat Cancer* 2022
- TRUST4 references — Song et al., *Nat Methods* 2021 (hg38 BCR/TCR FASTA, IMGT)
- HGNC gene-name annotations — HUGO Gene Nomenclature Committee

Consult the original publications and the IOBRpy repository for the terms
that apply to each reference before using them beyond research purposes.
