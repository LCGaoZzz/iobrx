iobrx 0.2.0 provides precompiled installation for **CPython 3.11 on Linux
x86-64 / WSL2**, with no Rust/C++ compiler or AVX-512 requirement on the user
machine. Native Windows, macOS and ARM are not validated full-stack targets.

```bash
python -m pip install --only-binary=:all: iobrx==0.2.0
python -c "import iobrx; print(iobrx.backend_info())"
```

Tsinghua mirror, after synchronization:

```bash
python -m pip install --only-binary=:all: -i https://pypi.tuna.tsinghua.edu.cn/simple iobrx==0.2.0
```

The release includes a manylinux2014 wheel and rebuildable source archive,
SHA-256 checksums, and the immutable digest of the tested container:

```bash
docker run --rm ghcr.io/lcgaozzz/iobrx:0.2.0
docker run --rm -v "$PWD:/work" -w /work ghcr.io/lcgaozzz/iobrx:0.2.0 python analysis.py
```

The container uses a digest-pinned Python 3.11.15 / Debian 12 base and a
hash-locked dependency set. Its executed tutorials and public data are in
`/opt/iobrx/tutorials`; use `container-digest.txt` to pin the entire image.

This release removes the mandatory AVX-512 build, adds explicit native/Python
backend selection and diagnostics, and supplies 12 executed analysis notebooks
with measured desktop timings and figures refined in two rounds. English and
Chinese README pages link directly to each tutorial.

Release gates cover all 34 API/portability/official-data parity tests using
the actual installed wheel and again inside the container, plus disabled-native
and baseline NumPy sorting checks. Exact parity is scoped to the tested inputs
and pinned numerical dependencies; stochastic CIBERSORT P-values are excluded
from exact-equality assertions. CPU/BLAS/platform-independent bit equality is
not promised.

See [the changelog](https://github.com/LCGaoZzz/iobrx/blob/v0.2.0/CHANGELOG.md)
and [tutorial gallery](https://github.com/LCGaoZzz/iobrx/blob/v0.2.0/tutorials/README.md).
