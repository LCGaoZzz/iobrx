# iobrx 0.3.1

This is a patch release following the merged Omicos bulk-input integration.

## Included

- Affinity-aware default thread selection through `available_cpu_count()`;
  explicit `n_threads` values and `iobrx.set_threads()` values remain
  authoritative.
- The companion Omicos harness now carries the merged h5ad input, exact
  sample/cohort alignment and batch orchestration integration.
- No numerical solver, dependency pin, or scientific parameter changes are
  included in this release.

## Validation

The source consistency gate checks the synchronized Python, Rust, runtime,
Docker and release-note versions. The merged Omicos integration was validated
with its focused harness and catalog tests; h5ad-specific cases remain
optional when AnnData is not installed.

Install the published CPython 3.11 Linux wheel with:

```bash
python -m pip install --only-binary=:all: iobrx==0.3.1
```

The release workflow also publishes the matching source archive and versioned
container after the `v0.3.1` tag passes its checks.
